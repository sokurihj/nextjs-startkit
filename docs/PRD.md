# 프로젝트 요구사항 (PRD)

## 개요
Next.js 16 기반 모던 웹 애플리케이션 스타터킷

## 기술 스택
- **Framework**: Next.js 16.2.6 (App Router)
- **Runtime**: React 19.2.4 + TypeScript 5.9.3
- **Styling**: TailwindCSS v4 + shadcn/ui
- **Forms**: React Hook Form + Zod
- **Theme**: next-themes (다크모드 지원)

## 핵심 기능 요구사항
- [ ] 반응형 레이아웃
- [ ] 다크/라이트 모드 전환
- [ ] 폼 유효성 검사
- [ ] 컴포넌트 기반 UI

## 비기능 요구사항
- 빌드 오류 없이 배포 가능한 상태 유지
- 커밋 전 lint + 타입 체크 통과 필수
